What it does

Security & signing

PAdES B-LT/B-LTA digital signatures with visible appearances, AES-256 and certificate-based encryption, SHA-256 only.

Learn more →

Redaction you can trust

Content-stream excision — never black rectangles — with an optional sanitize pass, overlay text and word-list pattern marking.

Learn more →

OCR ensemble

Tesseract and RapidOCR PP-OCRv5 run in parallel with word-level ROVER fusion, preprocessing and a word-level review screen.

Learn more →

Real editing

Inline text edits with spacing and opacity, image move/resize/rotate/restack, a 13-tool annotation surface, forms and page operations.

Learn more →

Batch & hot-folder

Multi-step presets: Bates numbering, redaction, OCR, merge, compression, export — plus hot-folder ingest. All with inline error reporting.

Learn more →

Accessibility

An accessibility checker with jump-to-issue rows, Tag Document for untagged files, and full keyboard access (F6 region cycling, F1 help).

Learn more →

Why GlyphPDF

  • Nothing to install first. Qt 6, the PDF and OCR engines, runtimes and OCR models are all bundled inside the download — installer or portable ZIP.
  • Processed 100% locally. Every export carries a local-processing notice; document content never leaves the machine (the optional AI panel talks to a local Ollama only).
  • Open source, Apache-2.0. No subscription, no account, no cloud dependency — the whole source is on GitHub.
  • Honest by design. Unsupported capabilities are disabled with an explanation instead of pretending; a verified parity scorecard tracks every feature domain.

Verified feature parity

The repository carries a code-level parity scorecard that reconciled the July competitive audit against main — every claim backed by the producing function and a pinning test. Verified average: 8.6/10 across 16 feature domains (September 2026).

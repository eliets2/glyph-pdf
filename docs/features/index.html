Features

Every claim on this page is drawn from the repository's own documents: the README, the CHANGELOG, and the code-level parity scorecard that reconciled the July 2026 competitive audit against main — each disposition backed by the producing code and a pinning test.

Sources: README.md · CHANGELOG.md · PARITY-SCORECARD-2026-09-30.md (verified average 8.6/10 across the 16 domains below).

The 16 feature domains

Each domain links to its guide. The score is the September 2026 verified grade from the scorecard, not a marketing number — open items are named there too.

Document viewing & navigation

verified 9.0/10

Single, Continuous and Two-Page layouts; Presentation and Full Screen; engine-side page rotation; real hyperlink navigation with a scheme allow-list; Night Mode RGB inversion; Dark/Light/High-Contrast themes and Eye Care mode. Locked by TestViewParity, which characterizes every view mode.

Text & object editing

verified 8.5/10

Inline text editing with letter spacing, line spacing and opacity; image move, resize, rotate by angle, replace, delete, restack and opacity — all written into the PDF; Cut/Copy/Delete and a real eraser; Find & Replace with a redact-all option.

Annotations & markup

verified 8.5/10

One markup surface (the ribbon Comment tab) with 13 tools: highlights, underlines, strikeout, squiggly, notes, shapes, pencil/ink, callouts and stamps. Shapes and freehand persist as real PDF subtypes (/Square, /Circle, /Line, /Ink); a dynamic stamp library with custom stamps and ${author}/${date} placeholders.

OCR

verified 8.5/10

Tesseract and RapidOCR PP-OCRv5 engines run in parallel with layout detection, a preprocessing pipeline (deskew, binarize, denoise), 0/90/180/270 orientation detection, word-level confidence-weighted ROVER fusion, a word-level review screen, and Accept that exports a searchable MRC PDF/A.

Conversion

verified 8.5/10

PDF to Word (.docx), Excel (.xlsx with real table columns), HTML, images, CSV and text — real OOXML writers with engine tracking, an honest fallback warning and a local-processing notice on every export. PDF/A export presets including High Quality PDF/A, Web Optimized (linearized via qpdf) and Legal Archive.

Forms

verified 8.0/10

Text fields, checkboxes, radio buttons, dropdowns, date/numeric/calculated fields; fill and fill-and-lock; required flags and tooltips persist; a disclosed auto-detect heuristic with review-before-commit; AcroForm Calculate/Format/Keystroke/Validate scripts in a sandboxed quickjs-ng runtime with a CPU deadline.

E-signatures

verified 9.0/10

PAdES B-LT/B-LTA digital signatures with DSS/VRI, a certify selector, and a Draw/Type/Upload/Initials signature picker where each signature is a real PDF annotation. Visible ETSI-layout appearances, on-page validity badges, Validate-All summaries, session cache, and Prepare Request for other signers.

Redaction

verified 9.0/10

Secure redaction by content-stream excision — never black rectangles — with Mark Region/Mark All (explicit page lists), word-list import, named PII presets (email, US phone, SSN), overlay text burn-in, an optional sanitize pass default-ON, one-transaction saves with a SHA-256 source check, and a proof step that refuses to certify what it cannot verify.

Page management

verified 8.5/10

Rotate, crop, resize, reorder (drag-and-drop on the thumbnail grid), insert, extract, multi-part split (_part{n}), merge with real success/failure reporting, headers/footers/page numbers, Bates numbering (including cross-document in batch), and text/image watermarks.

Document comparison

verified 9.0/10

Two-document compare with page alignment (deterministic fingerprints, mid-insert aware), a changes tree with change-type filters, explicit rows for added/removed pages, side-by-side panes and printable reports.

Security & encryption

verified 8.5/10

AES-256 password encryption; certificate-based encryption with a multi-recipient picker; document sanitization (15+ vectors); Set Expiry Date with SafeSave transaction protection; expiry gates the whole mutating tool set; SHA-256 only for signature hashing; machine policy shows admin-managed settings as "Managed by policy".

Batch & hot-folder

verified 8.5/10

Batch processing with inline error reporting and named presets: Bates lane, rename-on-conflict, stop-on-failure, import/export, per-step measured-bytes reports, hot-folder ingest, and a multi-step preset editor. Batch OCR with language selection and low-confidence-word notes; multi-pattern redaction in a single load/find/apply/save pass.

Compression

verified 8.0/10

Real JPEG quality/DPI re-encoding, SMask-aware duplicate-image dedup, unused-object sweep, full-sanitize metadata strip, configurable DPI presets, measured before/after size readout — and MRC layered compression (JBIG2 foreground + JPEG2000 background) that measured 30.4× on an A4 scanned test page.

Accessibility checker

verified 8.5/10

An accessibility checker with jump-to-issue rows (including reading order per ISO 32000-2 §14.7.2 /Pg inheritance), async analysis off the UI thread, and Tag Document, which builds a structure tree for untagged documents while preserving images and marked content.

Search

verified 8.5/10

Document search with Match Case, Whole Words and Regex (a shared matcher also powers redact-all, with an honest page-level note when inline highlight is unavailable), bookmarks, thumbnail navigation with zoom controls, and full keyboard accessibility (F6 region cycling, F1 help).

File import & export

verified 8.5/10

Unified Open routing for PDFs, images and Office documents (drag-and-drop with drop plans; optional LibreOffice import), export presets with a runtime badge of which engine actually ran, verified qpdf linearization, and bookmark/hyperlink round-trip preservation on save.

Also on board

  • Print preview with page setup — paper size, orientation, margins, scaling (README: Print & Export).
  • AI Chat panel — local Ollama only, with a loopback guard; no document content leaves the machine (README: UI; CHANGELOG hardening).
  • Auto-update — JSON manifest, SHA-256 verified downloads, consent at every stage; the updater refuses unsigned installers by design (README: Auto-Update).
  • Localization — English ships today; Arabic, French and German translation scaffolding (1394 strings each) is in place, packages pending (README: Localization).

Honest limits

The scorecard's "still-open" list is public, on purpose. Named gaps include: QuadPoints text-anchored highlighting (highlights currently persist as drag rectangles), font subsetting (the checkbox is disabled with an explanation), OCR output-mode choice (searchable-MRC export only), selective sanitize with a pre-commit summary, recursive hot-folder watching, and Text/PowerPoint in the batch format list. See the scorecard for the full, evidence-linked list.

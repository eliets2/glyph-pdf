Download

You need nothing but the app itself. Qt 6, the PDF and OCR engines, the C++ and Visual C++ runtimes and the OCR models are all bundled inside the download — get it and run it.

Installer (recommended)

GlyphPDF-x64.msi — double-click, Next, Finish. Adds Start-menu and desktop shortcuts and an "Open with GlyphPDF" entry for PDFs.

Get the latest release

Portable (no install)

GlyphPDF-x64-portable.zip — unzip anywhere, including a USB stick, and run GlyphPDF.exe. Nothing is written to the registry.

Get the latest release

System requirements

Windows 10 (version 1607+) or Windows 11, 64-bit. 4 GB RAM recommended for OCR on large documents. That is the entire list.

Verify your download

Every release is published with a .sha256 sidecar. Check the file before installing:

Get-FileHash .\GlyphPDF-x64.msi -Algorithm SHA256

Compare the output with the value in the release's .sha256 file. The in-app updater performs the same SHA-256 verification (plus an Authenticode signature check) before it ever offers to install anything.

Package manager

A winget package (Glyph.GlyphPDF) will follow once releases are code-signed.

Updates

The in-app update checker reads the manifest at updates/latest.json, requires your consent at every stage, and is dormant until a code-signed release ships — it refuses unsigned installers by design. The on-launch check can be turned off in Preferences > Updates.

Release notes, assets and checksums live on the GitHub Releases page. Source code: github.com/eliets2/glyph-pdf.

Viewing & Navigation

GlyphPDF's viewer offers Single, Continuous and Two-Page layouts plus Presentation and Full Screen modes, engine-side page rotation, real hyperlink navigation (with a scheme allow-list so unsafe links are never opened), thumbnail navigation, Night Mode RGB inversion, and Dark/Light/High-Contrast themes with Eye Care and Night reading modes. Every view mode is characterized by the TestViewParity suite.

Status: parity scorecard §9.1 verified 9.0/10. Claims sourced from README.md, CHANGELOG.md and docs/audit/PARITY-SCORECARD-2026-09-30.md.

Tips

  • Alt+Left / Alt+Right navigate back / forward; Ctrl+0 restores actual size; Ctrl++ / Ctrl+- zoom (README keyboard table).
  • F11 toggles Full Screen; F1 opens the keyboard-shortcuts help at any time.
  • Two-page mode composites annotations and search highlights onto the spread, so markup stays visible in book view.

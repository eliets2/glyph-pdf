Conversion & Export

Convert PDFs to Word (.docx), Excel (.xlsx with real table columns), HTML, images, CSV and text using real OOXML writers, with a runtime badge of which engine actually ran and an honest fallback warning if a format degrades. Export presets cover High Quality PDF/A, Web Optimized (linearized via qpdf and verified) and Legal Archive. Every export carries a local-processing notice: no internet, no upload.

Status: parity scorecard §9.5 + §9.16 verified 8.5/10. Claims sourced from README.md, CHANGELOG.md and docs/audit/PARITY-SCORECARD-2026-09-30.md.

Tips

  • Office documents (.docx/.xlsx/.pptx/.odt) can be opened or dropped directly — optional LibreOffice import is auto-detected with an in-app download prompt if absent.
  • PDF/A validation uses veraPDF as a subprocess (never linked in-process); the app prompts to fetch it on first use.
  • Batch conversion covers Word/Excel/HTML/Image/Csv today — Text and PowerPoint in batch are a named open item.

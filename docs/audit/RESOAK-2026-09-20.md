## 1. Reboot-resilience mechanics (this lane's core requirement)

The first soak's single point of failure was a loop that survived lane exit
but not OS restart. The v3 loop adds:

1. **Heartbeat** — the loop rewrites `D:\resoak-48h.heartbeat` every pass
   (atomically via tmp+move). A healthy pass is at most ~17 min (900 s ctest
   cap + 60 s app cycle + pause), so the heartbeat can never be >30 min old
   while the loop lives.
2. **Relaunch guard** — `D:\resoak-48h-relaunch.bat`: exits immediately if
   `D:\resoak-48h.done` exists (window completed) or the heartbeat is <30 min
   old (live loop — prevents double loops); otherwise relaunches
   `D:\resoak-48h.bat` hidden via PowerShell `Start-Process`.
3. **Logon hook** — Scheduled Task **`GlyphPDFResoak`** (trigger
   `MSFT_TaskLogonTrigger`, user `PCELIE\User`, state Ready, created via
   `Register-ScheduledTask`; `schtasks /create /sc onlogon` was
   access-denied from this non-elevated shell, the ScheduledTasks module was
   not). Its target is `wscript.exe D:\resoak-48h-relaunch.vbs`, a hidden
   wrapper (`Run …, 0, False`) so a logon never shows a window.
4. **Resume semantics** — `D:\resoak-48h.state` (`FIRSTSTART=` + `PASS=`,
   written atomically each pass). On launch with state present the loop logs
   `=== RESTART DETECTED resuming at pass N - first start was …, end-by
   remains …, pass numbers continue ===` and continues: pass numbering never
   resets, the log is append-only, the 48 h window stays pinned to first
   start. Wall-clock accounting therefore counts total elapsed time including
   downtime across any number of reboots.
5. **Completed marker** — the loop writes `D:\resoak-48h.done` at its
   `=== SOAK END ===` line so the guard never restarts a finished soak.

**Live proof (2026-09-20 ~21:04+03, deliberate drill):** the running loop was

`=== SOAK END after N passes total … ===` plus `D:\resoak-48h.done`. Every
`RESTART DETECTED` marker is a survived restart — with this lane's design a
Windows Update reboot is an expected event, **not** a termination; the

crash suspects. Failing tests classify per verdict §4 plus this doc's §2
